Playwright with JavaScript course syllabus

What you will learn, module by module.

1. JavaScript and TypeScript for testers

  • ES6 essentials: functions, arrays, objects, async/await

2. Playwright fundamentals

  • Setup with Node.js and npm

Playwright with JavaScript: frequently asked questions

Should I learn Playwright with Python or JavaScript?

Both work well. Choose JavaScript or TypeScript if you work with web developers or want the most feature-rich test runner. Choose Python if you are new to coding. Our trainers will help you decide in the free demo class.

Do I need JavaScript knowledge to start?

No. We teach the JavaScript and async concepts you need before moving into Playwright.

Does the course cover TypeScript?

Yes. We cover the TypeScript basics that are used in Playwright projects.

Can I move from Selenium to Playwright after this course?

Yes. Many learners join after working with Selenium. You will learn how Playwright's locators and waiting differ so you can migrate existing tests.
