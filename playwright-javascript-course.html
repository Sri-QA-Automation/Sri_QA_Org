Phase 0: JavaScript Essentials for Test AutomationJavaScript, TypeScript Foundations

JavaScript Setup & Basics

  • What is automation testing and why Playwright? Architecture advantages over legacy frameworks.
  • JavaScript for automation testing: Syntax characteristics, node runtime vs browser runtime.
  • Installing Node.js and VS Code: Environment configuration and extensions setup.
  • Understanding npm & package.json: Dependency management, scripts, and initialization.
  • Writing and running first JavaScript program: Terminal execution and debugging fundamentals.

Assignment: Print "Welcome to Playwright Automation" using JavaScript.

Core JavaScript for Testers

  • Variables: Scope and mutability using var, let, and const.
  • Data types & operators: Primitive vs complex types, comparison and logical operators.
  • Conditional statements: Decision-making using if, else if, and else.
  • Loops: Iteration mechanics with for, while, and forEach.
  • Functions: Declaration, expressions, normal vs arrow functions.
  • Arrays & Objects for test data: Data structures for organizing and querying test inputs.

Assignment: Write a JavaScript function to validate login credentials.

Useful JavaScript Concepts for Automation

  • File handling using fs module: Reading and writing synchronous and asynchronous files.
  • Exception handling: Managing execution flow with try...catch...finally.
  • Import / export modules: Modular code organization using CommonJS and ES modules.
  • Basic understanding of Classes & Objects: Object-oriented fundamentals for page models.
  • Async programming basics: Asynchronous execution patterns with async / await.
  • Promises & callback understanding: Managing asynchronous lifecycles and state resolve/reject.

Assignment: Read user data from a JSON file and print usernames.

Special Module: TypeScript for Playwright Automation

  • What is TypeScript and Why to Use It?
    • Introduction to static typing in automation.
    • TypeScript vs JavaScript comparison.
    • Benefits of compile-time checking in large test suites.
    • Scalability advantages for enterprise frameworks.
  • Setting Up TypeScript Project with Playwright:
    • Installing TypeScript compiler and definitions.
    • Initializing Playwright natively with TypeScript.
    • Understanding compiler options in tsconfig.json.
    • Project structure best practices for TS automation.
    • Executing Playwright tests in native TypeScript.
  • Type Annotations and Inference:
    • Primitive type annotations (string, number, boolean).
    • Explicit function return types and parameter typing.
    • Defining array and custom object types.
    • Leveraging type inference for cleaner code.
    • Practical usage patterns in automation scripts.
  • Enums and Union Types:
    • Numeric vs string enums for test configuration.
    • Practical enum usage in element state handling.
    • Union types for flexible data inputs.
    • Literal types for strict browser and environment selection.
  • Classes and Objects in TypeScript:
    • Object-oriented class construction in TS.
    • Class constructors, properties, and methods.
    • Access control with public, private, and protected modifiers.
    • Designing a strongly typed Page Object Model.
    • Enforcing strict typing across Playwright Page and Locator instances.
Phase 1: Playwright FoundationsCore Playwright & TDD Mechanics

Getting Started with Playwright

  • What is Playwright? Architecture & features: WebSocket protocol connection, multi-browser architecture.
  • Supported browsers & Playwright Test Runner: Chromium, Firefox, WebKit engine mechanics.
  • Installing Playwright with TypeScript: Project bootstrap via @playwright/test.
  • Browser launch options: Headed vs headless execution, viewport configuration.
  • Writing first Playwright test: Browser instantiation, navigation, interaction, and screenshot output.

Assignment: Automate Google search and capture screenshot.

TDD (Test-Driven Development) Approach in Playwright

  • What is TDD? Applying the Red-Green-Refactor cycle to UI and API test automation workflows.
  • Writing Tests First: Designing test requirements, boundary checks, and assertions before implementing page actions.
  • Unit Testing Logic in Test Scripts: Applying TDD principles to utility functions, helpers, and API payload builders.
  • Structuring for Maintainability: Clean code principles to keep TDD-driven test suites readable and robust.

Assignment: Write a test suite for a registration form using strict TDD (Red-Green-Refactor phase tracking).

Element Interactions

  • Actions: Performing basic interactions with click(), fill(), type(), and press().
  • Keyboard & mouse actions: Hovering, key combinations, drag-and-drop actions.
  • Handling dropdowns, checkboxes & radio buttons: Select options, state toggling, and verification.

Assignment: Automate login flow on a demo website.

Locators & Selectors

  • CSS vs XPath: Syntax patterns, performance, and maintainability trade-offs.
  • Semantic locators: Finding elements by Text, Role, Label, and Placeholder attributes.
  • Locator APIs: Utilizing locator(), getByText(), getByRole(), and nth().
  • Best practices for stable locators: Chaining, filtering, and avoiding fragile DOM paths.

Mini Project: Automate product search & validation on a demo e-commerce site.

Assertions & Validations

  • Playwright expect assertions: Auto-waiting assertion library functions.
  • Validating state: Text contents, attribute values, and element visibility checks.
  • Soft assertions: Continuing execution on non-critical assertion failures using expect.soft.
  • Handling alerts, popups & dialogs: Event listeners for JS alerts, confirms, and prompts.

Assignment: Automate form submission and validate success message.

Synchronization & Error Handling

  • Auto-waiting mechanism: Under the hood actionability checks (visible, stable, enabled).
  • Explicit waits: Targeted synchronization with waitForSelector() and waitForLoadState().
  • Handling timeouts & retries: Global vs per-action timeout configurations.
  • Capturing failure artifacts: Automated screenshot and trace collection upon failure.
  • Retry strategies for flaky tests: Identifying, isolating, and resolving transient script failures.

Assignment: Fix a flaky test using proper synchronization.

Phase 2: Framework Concepts & ReusabilityArchitecture, POM & BDD Integration

Page Object Model (POM) – Basic

  • What is POM & why we use it: Design pattern benefits for maintainability and DRY principles.
  • Creating Page classes in TypeScript: Encapsulating page state and behavioral methods.
  • Separating locators & methods: Defining locators in constructors vs dynamic getters.
  • Reusable functions: Creating modular actions across pages.
  • Structuring tests folder: Separating specification files from object models.

Assignment: Refactor login test using POM.

Advanced POM Project Building using TypeScript

  • Framework Folder Structure: Scalable layout using pages/, tests/, utils/, fixtures/, test-data/, and config/.
  • Base Page Implementation: Creating BasePage.js with centralized wait handling and dynamic wrappers.
  • Reusable Utilities: Custom logging adapters, dynamic data generators, and browser wrappers.
  • Data Management: Externalizing inputs via JSON files and .env environment files.
  • Fixtures & Hooks Integration: Utilizing beforeEach/afterEach hooks and custom Playwright fixtures for setup.

Mini Project: Build a scalable Login + Search module using advanced POM structure.

BDD Framework with Playwright & Cucumber

  • Introduction to BDD & Cucumber: Writing behavioral specifications in Gherkin (Given, When, Then, And, But).
  • Setting up Cucumber with Playwright: Package installation, cucumber.js configuration, feature file layout.
  • Step Definitions & Glue Code: Mapping Gherkin steps to async Playwright automation execution code.
  • Cucumber World & Hooks: Browser context management, Before/After lifecycle hooks, cross-step state sharing.
  • HTML Reporting & Tagging: Configuring execution reporters and selective run tags (e.g., @smoke, @regression).

Mini Project / Assignment: Convert an existing login/checkout test into a BDD feature file with Cucumber step definitions.

Iframes, Popups & File Handling

  • Handling iframes & nested frames: Switching context using frameLocator().
  • Multiple windows & popups: Handling multi-page contexts and event-driven tab opening.
  • File upload & download automation: Intercepting file chooser dialogs and download events.

Mini Project: Automate iframe-based form & file download.

Cookies, Sessions & Configurations

  • Managing cookies & local storage: Inspecting, inserting, and clearing browser storage states.
  • Reusing authenticated sessions: Bypassing repetitive login flows using saved storage states.
  • Using config files & environment variables: Managing multi-env settings via playwright.config.js.
  • Storage state handling: Pre-authenticating tests using global setup configurations.

Assignment: Reuse login session across multiple tests.

Debugging & Codegen Tools

  • Playwright Codegen: Recording user interactions to auto-generate baseline test scripts.
  • Playwright Inspector: Step-through execution, locator debugging, and live page evaluation.
  • Trace Viewer: Inspecting action logs, DOM snapshots, network traffic, and visual state post-execution.
  • Debugging flaky tests: Isolating timing issues using trace artifacts.

Assignment: Generate test using Codegen and enhance it.

Logging & Reporting

  • Logging with console & custom loggers: Structuring execution logs for operational visibility.
  • Playwright HTML reports: Navigating and configuring built-in HTML reporters.
  • Attaching screenshots & traces: Programmatically attaching contextual artifacts to test reports.
  • Custom reporters: Building custom event handlers for third-party reporting frameworks.

Assignment: Generate HTML report with screenshots.

Phase 3: Test Execution, Data-Driven & CI/CDData-Driven Testing, CI/CD Pipelines

Playwright Test Runner

  • Test structure & configuration: Managing options inside playwright.config.js.
  • Hooks: Managing setup and teardown lifecycles with beforeAll, afterAll, beforeEach, afterEach.
  • Test grouping & tagging: Categorizing tests with test.describe and tag annotations.
  • Retries & parallel settings: Configuring worker threads and dynamic retries based on execution mode.

Assignment: Run tests using tags and hooks.

Data-Driven Testing

  • Parameterized tests: Executing same test logic against dynamic dataset arrays.
  • Reading data from JSON: Parsing multi-user configurations into test iterations.
  • Running tests for multiple users: Validating role-based access controls dynamically.
  • Environment-based test execution: Switching endpoint targets via command line switches.

Assignment: Automate login for multiple users from JSON.

Parallel & Cross-Browser Execution

  • Parallel execution: Understanding worker processes and isolated browser contexts.
  • Running tests across engines: Concurrent execution across Chromium, Firefox, and WebKit engines.
  • Browser-specific configuration: Customizing launch args, viewports, and capabilities per browser.

Mini Project: Validate end-to-end flow across browsers.

CI/CD Integration

  • Git & GitHub basics: Version control concepts, branching, committing, and remote syncing.
  • GitHub Actions setup: Configuring workflow YAML files for pull-request validation.
  • Running Playwright tests in pipeline: Managing headless browsers and dependencies in CI containers.
  • Generating reports in CI: Publishing build artifacts and HTML test reports directly to GitHub.

Assignment: Push code to GitHub and trigger CI pipeline.

Reporting & Maintenance

  • Advanced HTML reports: Aggregating historical trends and failure analytics.
  • Test data management: Strategies for cleaning up dynamic test artifacts post-execution.
  • Framework cleanup best practices: Code refactoring, dependency updates, and deprecation checks.
  • Version upgrades: Safely updating Playwright binaries and driver dependencies.

Assignment: Create execution summary report.

Hybrid UI + API Testing

Geolocation & Network Simulation

Visual Regression Testing

    • Leveraging inline AI assistance to diagnose syntax errors and refactor complex helpers.
  • Model Context Protocol (MCP) Servers in QA:
    • Architecture of MCP Servers and integration between LLMs, IDEs, and local environments.
    • Configuring local MCP servers to pass real-time runtime state and logs to AI assistants.
    • Automated diagnostic loops: Using AI context to analyze trace files, identify selector mutations, and patch broken tests.

Mini Project / Assignment: Use GitHub Copilot to scaffold a Page Object file, and leverage an MCP setup to auto-diagnose and fix a broken test script.

Playwright with JavaScript: frequently asked questions

Should I learn Playwright with Python or JavaScript?

Both work well. Choose JavaScript or TypeScript if you work with web developers or want the most feature-rich test runner. Choose Python if you are new to coding. Our trainers will help you decide in the free demo class.

Do I need JavaScript knowledge to start?

No. We teach the JavaScript and async concepts you need before moving into Playwright.

Does the course cover TypeScript?

Yes. We cover the TypeScript basics that are used in Playwright projects.

Can I move from Selenium to Playwright after this course?

Yes. Many learners join after working with Selenium. You will learn how Playwright's locators and waiting differ so you can migrate existing tests.
